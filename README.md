# ドローンの構造 — 3Dビジュアライザー

550クラスのクアッドコプターを部品単位で分解・透視・断面表示できる、単一HTMLの3D教材。
モデルは外部ファイルを使わず、すべて three.js のコードから手続き的に生成しています。

**公開URL**: https://drone-anatomy-3d.hiro-k61.workers.dev/

登録講習機関の学科講習、住民説明会、行政での説明に使うことを想定しています。制度の記述は
出典と基準日を添え、**判定はしません**（「求められている」「確認する」で止めます）。

## できること

### みる
- **部品をクリックすると解説** — 役割・構造・仕様例・点検ポイント。全40種
- **部品の検索** — 名前でも言い換えでも引けます。電池でバッテリー、羽でプロペラ、頭脳でFC
- **分解スライダー** — 組み立て順に部品が離れていく
- **5つの見え方** — 通常 / X線 / 線画 / 断面（モーター内部とバッテリーのセル）/ 設計図（全部品を見ると解放）
- 単独表示・非表示、視点プリセット、ラベル、大きく読む、記念写真

### とばす
- **飛行の原理** — ホバリング・上昇・前進・横移動・旋回で、各モーターの増減速を矢印と％で可視化
- 仮想スティック（モード1/2）、気流の可視化、機体を指ではじくと姿勢が戻る

### つかう
- **用途で変わる装備** — 防災・農業・点検など。追加する機器と強化する部品が色で分かる
- **重さ・お金** — 部品ごとの質量の積み上げ、重心マーカー、参考価格、実寸の人型との対比
- **重量区分** — 100g と 25kg の線を対数軸で示す（制度の注記が有効なとき）

### もしも
- **まちがえたら（6つ）** — プロペラ逆付け、ESC配線の入れ替え、FC取付向き、落下など。壊れるところまで演じます
- **機体がこうなったら（4つ）** — 電波切れ、電池残量、GNSS喪失、強風
- **こんな場所・時間なら（6つ）** — 夜に飛ばす、見えなくなる（目視外）、空港が近い、落ちる範囲（第三者の上空）、人が近づいた、人を入れない（立入管理措置）
- 各場面は「状況 → 機体の反応 → 働く部品 → できること・やること」の4段で進みます

### 専門
- **センサーが見ている波形** — ジャイロ・加速度・気圧高度・コンパスのずれ。防振の有無、電流でコンパスが狂う、電波の形、10分ホバーの熱
- **消耗の早送り** — 0〜1000回で部位ごとの進み方、交換の目安、年間維持費
- **設計の計算** — KV・セル数・プロペラ・重量から推力重量比／飛行時間／先端速度など。A/B比較つき

### 制度レイヤー（設定 › 制度）
- 部品の解説に「⚖ 制度では」、場面の最終カードに制度の1行、事故の「報告するなら」
- **教則第5版との対応表** — 章から引く／画面から引くの両方向。章を選ぶと、その話に出せる画面が並びます
- **飛行前の点検・確認シート** — 法令・教則が挙げる確認項目を現場の動線の順に並べ、この機体の点検ポイントを足して印刷
- 出典と基準日は設定の「制度の出典と基準日」に一覧

### 共有・授業
- **共有リンク（🔗）** — いま見えている画面をURLにして渡せます。部品・見え方・分解・場面・視点まで戻ります
- **授業・説明会モード** — `?lesson=class45`（45分授業）/ `?lesson=town10`（10分住民説明会）。`&step=N` で途中から
- ワークシートの印刷、ふたりクイズ、やさしい日本語／English、読み上げ、ライト/ダーク、スマホ対応

## 構成

| パス | 役割 |
| --- | --- |
| `src/data.js` | 部品の解説と仕様値、飛行・用途・もしも・授業の定義、制度と教則の表、点検シートの骨組み |
| `src/materials.js` | 手続き生成テクスチャ（カーボン綾織・基板・ラベル）と材質 |
| `src/drone.js` | 全部品のジオメトリ生成と組み立て、人型フィギュア |
| `src/engine.js` | レンダラー・ポストプロセス・カメラ・表示モード |
| `src/physics.js` `src/airflow.js` | 姿勢制御の簡易モデル、モーター配分、気流 |
| `src/theater.js` `src/whatif.js` | まちがえたらの劇場、もしもの場面 |
| `src/scale.js` `src/codex.js` `src/live.js` | 重さ・お金、見た部品の記録、言語と読み上げ |
| `src/lesson.js` `src/expert.js` | 授業の台本と印刷、専門タブ（センサー・消耗・設計の計算） |
| `src/reg.js` `src/preflight.js` | 制度レイヤーと教則の対応表、飛行前の点検・確認シート |
| `src/share.js` `src/ui.js` `src/app.js` | 共有リンク、UI全般、起動とメインループ |
| `src/style.css` `src/index.html` | スタイルとテンプレート |
| `public/index.html` | **生成物**。これをCloudflareが配信する |
| `artifact.html` | **生成物**。Claude Artifact 用の本文断片 |

`src/` を編集して `python3 build.py` を実行すると、2つの生成物が作り直されます。
**生成物を直接編集しないこと。**

## 開発

```sh
python3 build.py
python3 -m http.server 8941 --directory .
```

`http://localhost:8941/public/index.html` を開きます。

### 検証

`docs/tests/*.js` は、ブラウザのコンソールに貼って実行する受け入れスクリプトです。
`window.__d.noRender = true` で描画を飛ばし、`window.__d.step(秒, fps)` で状態だけ進めます。
合格すると `⑥ OK` のような文字列を返します。

| ファイル | 範囲 |
| --- | --- |
| `p6-scale.js` | 重さ・お金・重心 |
| `p7-codex.js` | 見た部品の記録・設計図・記念写真 |
| `p8-live.js` | 言語・大きく読む・読み上げ・浮遊 |
| `p9-lesson.js` | 授業モード（`?lesson=class45` で開いてから） |
| `p10-whatif.js` | もしもの10場面（`__wtest(['signal'])` のように1つずつ） |
| `p11-13-expert.js` | センサー・消耗・設計の計算 |
| `pA-reg.js` | 制度レイヤー |
| `pB-share.js` | 共有リンクと部品検索 |

## デプロイ

`main` に push すると **Cloudflare Workers Builds** が自動でデプロイします（2026-09-11 接続済み）。

- ビルドコマンドは**空**。このリポジトリに `package.json` は無く、`public/index.html` は
  コミット済みの生成物をそのまま配信する
- デプロイコマンドは `npx wrangler deploy`、ルートディレクトリは `/`
- 手動で上げたいときは `npx wrangler@latest deploy`

`src/` を直したのに `python3 build.py` を忘れると、**古い `public/index.html` がそのまま
デプロイされてしまう**。これを防ぐため GitHub Actions（`.github/workflows/deploy.yml`）が
push のたびに再ビルドして差分が無いか検査します。差分があれば赤バツで知らせます。
このワークフローは検査専用で、デプロイはしません（`CLOUDFLARE_API_TOKEN` 未設定のため）。
