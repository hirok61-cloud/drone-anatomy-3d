# UI設計メモ（2026-09-11 UI/UXエージェントの助言を採用したもの）

## 土台: ドックを「やること」4タブに
- タブ: みる / とばす / つかう / もしも。文脈行はタブごとに最大6コントロール。
- 視点・ラベル・全画面はステージ右下の縦アイコン列(44px)へ。
- モーターは「▶回す／■止める」1トグル。速度3段は「くわしく」時のみ。
- `--dock-h` は ResizeObserver で実測値をセット。
- 説明面は `#noteCard` 1つに統一（原理の解説／質問の答え／用途の説明／シアター字幕）。
- トーストは1レーン（トップバー下・中央・同時1件・role=status）。

## 排他ルール
- とばす に入る: 分解>0→0へ、断面→通常へ。
- もしも 再生中: 他タブ・質問・スティック・部品選択は無効。Esc=やめる。
- 質問の act 実行時はスティック操作を中断。

## B1 触ると答える機体
- 「▶回す」でlive。機体に当たる指でcontrols無効化。<250ms & >600px/s=フリック、それ以上=押し続け。機体以外・2本指は回転/ズーム。
- 各モーター真上に%バッジ（ラベル機構流用）。M3 68% ▲。
- 仮想スティック: 88px(スマホ112)、ノブ40、遊び8%、モード1既定・記憶。
- かたむき: DeviceOrientationがある時だけボタン。事前説明シート→requestPermission。visibilitychangeでオフ。
- 導線: 回す3秒後にcoach「機体をはじいてみよう ›」。

## B2 スロー観察
- 「ゆっくり」= rpm 1/50、バッジ「1/50のはやさ」。「まわる向き」トグル。凡例カード（↺CCW=しま、↻CW=無地、灯火 ●赤 ■緑 ◆白）。

## B3 気流
- 「風をみる」トグル。停止中に押したら回すも入れる。分解>0/断面/壊れた場面では非表示。軽量は粒子半減、narrowは60%。

## B4 扉
- 初回の一問=coach吹き出し（時間で消さない・localStorage）。「？きく」ポップオーバー(320px)/ボトムシート(60%)、上6問+ほかの質問。
- 質問: 一覧が閉じ→parts光る(2回パルス)+focusOn+act→noteCard（[部品をくわしく›][つぎの質問›] とじる）。act.theaterは[やってみる▶]。
- つかう: 6チップ。keep=そのまま/up=橙縁+▲/ghost=半透明+＋/drop=20%+−。noteCardに重さ帯・時間帯・凡例・[もどす]。ghostタップ→簡易カード。
- 深さ切替はトップバー副題の位置。

## B6 重さ・お金・重心（パッケージ⑥ / 2026-09-11実装）
- 入口: つかうタブの文脈行「重さ・お金」トグル（`#scaleBtn`）。用途チップと排他。タブを離れると自動で解除。
- 入ると機体はホバー（`S.power=0.5`・free）し、積み上げバー（`#massBar`、デスクトップは左上・スマホはドック上の横バー）と重心マーカー、人型スケール（スマホ以外）が出る。
- 質量は `MASS`（親部品のみ40→31区分、内部部品は親に含める）。はじめてでは SIMPLE_KEYS 8 + その他 の9区分に丸める。合計 2.42 kg。
- モーター%バッジは「負担率」= (総重量/基準重量) × 前後配分 × 左右配分。負担率 1.35 超で赤（`.mbadge.over`）＋注記。
- バッテリーと荷物ゴーストは前後±45mmドラッグ可（`scaleTryDrag`、`pointerdown` の最初にフック）。重心は「設計上のつり合い点」からのずれで測る（`scale.cg0`）。
- ¥ボタンで3Dラベルを参考価格に差し替え、合計と注記（年・出典の但し書き）を必ず出す。
- 排他の追加: `setUse(id)` は id 指定時に重さモードを解除。`setTab` は use 以外へ移ると解除。

## B7 図鑑とカード（パッケージ⑦ / 2026-09-11実装）
- 発見 = 部品を選んで解説が1.5秒以上出たとき。母数は常に40。`#codexCount`（`12/40`）が増えた瞬間だけ0.6秒拡大。トーストは出さない。
- 今日の一部品は日付のハッシュで決まり、未発見なら 0.15〜0.30 の呼吸で光る（`stepCodex`）。通常モード・分解0・用途/重さ/質問/シアターでないときだけ。
- 解説カードに「今日の一部品」バッジと「豆知識」（`TRIVIA`、1部品1文）を出す。
- 40/40 で「設計図」モード（`data-mode="blueprint"`）を解放。線画の色と背景・床・グリッドだけを差し替える（`applyBlueprint`）。解放は `store('codexDone')`。
- 📷（`#photoBtn`）で 1600×1200 のポスターを生成。`navigator.share` が使えれば共有シート、無ければ `#photoPop` に画像を出して長押し保存。ダウンロードリンクは作らない。
- 称号・バッジ・ランキング・ストリーク・音は作らない。

## B10 もしもの5場面（パッケージ⑩ / 2026-09-11実装）
- 入口: もしもタブの2段目「もしも、外でこうなったら」（`#whatifCards`、5枚。深さに関わらず5枚とも出す）。
- 段階は `WHATIF_STAGES = ['状況','機体の反応','働く部品','できること・やること']`。theater 行（`#thStages`/`#thNext`/`#thQuit`）を流用し「ゆっくり」は隠す。
- 機体の反応はすべて小さく（姿勢±8°・移動0.25m以内）。`rth`（回頭→0.2m進む→着陸）/ `landSlow` / `driftHold`（位置は戻さない）/ `wind`（風上へ7°・気流を横に流す・風上側モーター1.15）/ `person`（機体は動かず人型が近づき灯火が点滅）。
- 「働く部品」は1.2秒ごとに順に点灯し、その部品のラベルだけ出す（`S.labelOnly`＋`buildLabels()`）。カードの番号付きリストが同期して増える。
- 最後は2欄（機体ができること／人がやること）＋`caveat`（「設定と点検が前提」等の限定）。これは必ず出す。
- 排他: `startWhatif` は `stopTheater` を、`startTheaterUI` は `stopWhatif` を呼ぶ。タブ移動で終了。

## B8 生きている機体と、みんなの土台（パッケージ⑧ / 2026-09-12実装）
- `S.alive`（設定「浮かせておく」・永続）。みるタブで何も選んでいない・分解0・通常モード・質問/シアター/もしも/授業/重さ/用途でないとき、0.8秒後にホバー（`alive.on`）。条件が外れると即着陸。とばすタブへ移ったときは飛行を引き継ぐ（着陸させない）。
- 生きている間もラベルを出し（`updateLabels` の live 判定）、%バッジと推力矢印は出さない（はじく・押すときだけ矢印）。ポインタの方へ yaw ±4° だけ向く（`body.lookYaw`、`stepFree` で目標を差し替え）。10秒放置で自動回転。軽量画質(0〜1)では強制オフ＋注記。
- 生きている機体を軽くタップ（8px未満・350ms未満）すると選択になる（フリックは従来どおり）。
- 大きく読む: `#bigBtn`（視点列）と設定トグル。文字1.18倍・3Dラベルを消し・`#bigBand` に選択中/ホバー中の部品名を1つだけ（28px、スマホ22px）。
- 言語: `S.lang ∈ ja/easy/en`（設定の先頭）。段階1 = `[data-i18n]` のUI文字・8部品の名前/役割/たとえ・12質問。40部品の解説は日本語のまま「— Japanese only —」を付ける。`partName()/partRole()/qText()/t()` を経由する。
- 読み上げ: `speak()`（Web Speech）。解説見出し・大きく帯・質問カードの🔊、設定「選ぶと自動で読む」。iOS のためクリックハンドラ内で直接呼ぶ。

## B9 授業・説明会モード（パッケージ⑨ / 2026-09-12実装）
- 入口: 設定の最上段「授業・説明会 ›」→ `#lessonPop` のコース2枚、または `?lesson=class45|town10&step=N`。授業中は URL を `replaceState` で同期（URL共有）。
- 右パネル `#inspector` を台本 `#lesson` に差し替える（同じ位置・同じシート挙動）。選んだ部品の名前と役割1文は台本パネル上部の `#lessonSel` に出す（右パネルが台本になっているため）。
- 段落切替のたびに `resetStage()` で気流・シアター・もしも・質問・用途・重さ・分解・モード・選択・スティック・スロー・電源を全部戻してから `act` を実行。未実装の `act` キーは黙って飛ばす。
- `act.alive` は授業中も浮かせる（`lesson.hover`）。キー: →/Space/PageDown 次、←/PageUp 前、Tab/Shift+Tab 部品めぐり（`TOUR_ORDER` 外→内・その部品のラベルだけ表示）、Q クイズ、Esc（中の物を閉じてから終了確認）。スマホは段落リスト上の横スワイプ。
- ふたりクイズ: ラベル全消し、出題部品が 0.3〜0.9 で呼吸、`答えを見る` で名前と役割だけ。得点・正誤・タイマー・音なし。設定からも単独起動できる。
- 印刷: `#printSheet` に線画の穴埋め図（番号バッジは左右余白に縦並び・引き出し線）＋記入欄＋ふりかえり3問＋URL。`body.print-preview` で画面上確認。


## 排他ルール（2026-09-12 更新・第3ラウンド）
「同時に1つ」の対象 = 質問・飛行デモ・用途・重さ・シアター⑤・もしも⑩・ふたりクイズ。入口で `stopOthers(keep)`（ui.js）を呼び、keep 以外を全部止める。
- `askQuestion` → `stopOthers('question')`（質問の act が起こす飛行デモは質問の一部として残す）
- `setFlight(f)` (f あり) → `'flight'` / `setUse(id)` (id あり) → `'use'` / `setScale(true)` → `'scale'`
- `startTheaterUI` → `'theater'` / `startWhatifUI` → `'whatif'` / `quizStart` → `'quiz'`
- 授業は「舞台の外側」として共存を許し、段落切替の `resetStage()` で全部戻す。alive・大きく読む・言語・読み上げは土台なので排他対象にしない。
- クイズ中は `select()` を拒否（トーストで案内）。シアター/もしも再生中は Esc 以外のショートカットを受けない。重さモード中は 1〜4/E を受けない。
- ⑩が隠した「ゆっくり」は `onTheaterChanged` の先頭で戻す。
