# UI設計メモ（2026-09-11 UI/UXエージェントの助言を採用したもの）

## 土台: ドックを「やること」4タブに
- タブ: みる / とばす / つかう / もしも。文脈行はタブごとに最大6コントロール。
- 視点・ラベル・全画面はステージ右下の縦アイコン列(44px)へ。
- モーターは「▶回す／■止める」1トグル。速度3段は「くわしく」時のみ。
- `--dock-h` は ResizeObserver で実測値をセット。
- 説明面は `#noteCard` 1つに統一（原理の解説／質問の答え／用途の説明／シアター字幕）。
- トーストは1レーン（トップバー下・中央・同時1件・role=status）。

## 排他ルール
- とばす に入る: 分解>0→0へ、断面→通常へ。
- もしも 再生中: 他タブ・質問・スティック・部品選択は無効。Esc=やめる。
- 質問の act 実行時はスティック操作を中断。

## B6 重さ・お金・重心（パッケージ⑥ / 2026-09-11実装）
- 入口: つかうタブの文脈行「重さ・お金」トグル（`#scaleBtn`）。用途チップと排他。タブを離れると自動で解除。
- 入ると機体はホバー（`S.power=0.5`・free）し、積み上げバー（`#massBar`、デスクトップは左上・スマホはドック上の横バー）と重心マーカー、人型スケール（スマホ以外）が出る。
- 質量は `MASS`（親部品のみ40→31区分、内部部品は親に含める）。はじめてでは SIMPLE_KEYS 8 + その他 の9区分に丸める。合計 2.42 kg。
- モーター%バッジは「負担率」= (総重量/基準重量) × 前後配分 × 左右配分。負担率 1.35 超で赤（`.mbadge.over`）＋注記。
- バッテリーと荷物ゴーストは前後±45mmドラッグ可（`scaleTryDrag`、`pointerdown` の最初にフック）。重心は「設計上のつり合い点」からのずれで測る（`scale.cg0`）。
- ¥ボタンで3Dラベルを参考価格に差し替え、合計と注記（年・出典の但し書き）を必ず出す。
- 排他の追加: `setUse(id)` は id 指定時に重さモードを解除。`setTab` は use 以外へ移ると解除。

- ⑫ 消耗: 着地し、丈夫な部品(robust)は `wearPaper`（薄いグレーの紙色）に落として消耗品だけ発色（must #e5484d / wear #e8a33d / crash #7c5cff）。**親部品→子部品の順に塗る**（モーターの後にプロペラ）。濃さ = 0.95×smoothstep(0.25, 1.0, flights/lo)、`setTint(..., {lerp: .85, emis: .06})`、交換時期(prog≥1)は emissive を 0.8s 周期で脈動。プロペラは黒いテクスチャなので `flatTint`（lerp .55/emis .2）。バーは hi 正規化（斜線帯 = lo〜hi）。「▶ 1000回まで早送り」(8s)・もどす・年に飛ぶ回数。費用は幅＋1フライトあたり＋内訳上位3＋「事故で壊れやすい」分の注記。1フライト≈15分の前提を明記。ねじ・コンデンサは robust（点検項目）。
- ⑬ 設計の計算: T=Ct·ρ·n²·D⁴、P=Cp·ρ·n³·D⁵、Ct=0.085√(P/4.5)、Cp=0.040(P/4.5)^0.9、K_LOAD .85、ETA .85、容量の80%。出力: 推力重量比（◎○▲＋目安）・ホバー余裕（回転数%と推力%）・飛行時間（約○分、実飛行は7〜8掛け）・先端速度（≤90 ◎）・全開の電流（≤60A ◎、Cレート）・g/W とディスク荷重・重心。ステップ応答は上段(指令・回転数)と下段(電流 n³・電圧、Rp=5mΩ/セル+5mΩ)の2枚、τ の説明つき。翼素ディスクは最大回転の翼端速度を赤とした相対ランプ（#233f9e→#c81e2b）、25/50/75% に m/s の目盛り文字、中心ほど透明、プロペラ面の下(y .038)、カラーバー凡例。フォームは `minmax(0,1fr)` グリッド＋単位列、`inputmode`、clamp。

## スマホ・横向きの決まりごと（2026-09-12 総点検）
- 画面の分岐は3つ: `@media (max-width: 1100px)`（右パネルをボトムシートに）/ `@media (max-width: 760px), (max-height: 520px)`（ドック・視点列の詰め）/ `@media (pointer: coarse)`（44pt・入力欄16px下限）。**coarse ブロックは CSS の末尾**に置く（前に置くと後続の宣言に負ける）。
- 視点列 `#viewCol` は横並び＋折り返し、`max-width: calc(100vw - 20px - safe-area)`。9個(くわしく)でも2行に収まる。
- シートは `#inspector` / `#lesson` / `#expert` が同じ挙動。専門だけ2段デテント（46vh ↔ 78vh、上スワイプで深く）。**高さ ≤520px（横向き）ではすべて `height: calc(100% - 12px)`**。`✕` は 1100px 以下でだけ出す（打ち消しはメディアクエリより前に書く）。
- `env(safe-area-inset-*)` を `--sal/--sar/--sab/--sat` に持ち、`#topbar` `#dock` `#viewCol` `.popover` `#noteCard` `#massBar` の位置に足す。
- 入力欄は `font-size: max(16px, …)`（iOS のフォーカス拡大を防ぐ）。`button` 等に `touch-action: manipulation` と `-webkit-user-select: none`、`.grabber` に `touch-action: none`。
- カメラ: 引ける上限は `camMax() = 3.2 × viewScale()`。台本の引き（`flyTo`）はその場で上限を広げ、場面を抜けるときは `camHome()` で機体の枠に戻す。**固定値で clamp しない**（縦画面で場面が枠に入らなくなる）。

## 排他ルール（2026-09-12 更新・第3ラウンド）
「同時に1つ」の対象 = 質問・飛行デモ・用途・重さ・シアター⑤・もしも⑩・ふたりクイズ・専門⑪⑫⑬。入口で `stopOthers(keep)`（ui.js）を呼び、keep 以外を全部止める。
- `askQuestion` → `stopOthers('question')`（質問の act が起こす飛行デモは質問の一部として残す）
- `setFlight(f)` (f あり) → `'flight'` / `setUse(id)` (id あり) → `'use'` / `setScale(true)` → `'scale'`
- `startTheaterUI` → `'theater'` / `startWhatifUI` → `'whatif'` / `quizStart` → `'quiz'`
- 授業は「舞台の外側」として共存を許し、段落切替の `resetStage()` で全部戻す。alive・大きく読む・言語・読み上げは土台なので排他対象にしない。
- クイズ中は `select()` を拒否（トーストで案内）。シアター/もしも再生中は Esc 以外のショートカットを受けない。重さモード中は 1〜4/E を受けない。
- ⑩が隠した「ゆっくり」は `onTheaterChanged` の先頭で戻す。
