# UI設計メモ（2026-09-11 UI/UXエージェントの助言を採用したもの）

## 土台: ドックを「やること」4タブに
- タブ: みる / とばす / つかう / もしも。文脈行はタブごとに最大6コントロール。
- 視点・ラベル・全画面はステージ右下の縦アイコン列(44px)へ。
- モーターは「▶回す／■止める」1トグル。速度3段は「くわしく」時のみ。
- `--dock-h` は ResizeObserver で実測値をセット。
- 説明面は `#noteCard` 1つに統一（原理の解説／質問の答え／用途の説明／シアター字幕）。
- トーストは1レーン（トップバー下・中央・同時1件・role=status）。

## 排他ルール
- とばす に入る: 分解>0→0へ、断面→通常へ。
- もしも 再生中: 他タブ・質問・スティック・部品選択は無効。Esc=やめる。
- 質問の act 実行時はスティック操作を中断。

## B6 重さ・お金・重心（パッケージ⑥ / 2026-09-11実装）
- 入口: つかうタブの文脈行「重さ・お金」トグル（`#scaleBtn`）。用途チップと排他。タブを離れると自動で解除。
- 入ると機体はホバー（`S.power=0.5`・free）し、積み上げバー（`#massBar`、デスクトップは左上・スマホはドック上の横バー）と重心マーカー、人型スケール（スマホ以外）が出る。
- 質量は `MASS`（親部品のみ40→31区分、内部部品は親に含める）。はじめてでは SIMPLE_KEYS 8 + その他 の9区分に丸める。合計 2.42 kg。
- モーター%バッジは「負担率」= (総重量/基準重量) × 前後配分 × 左右配分。負担率 1.35 超で赤（`.mbadge.over`）＋注記。
- バッテリーと荷物ゴーストは前後±45mmドラッグ可（`scaleTryDrag`、`pointerdown` の最初にフック）。重心は「設計上のつり合い点」からのずれで測る（`scale.cg0`）。
- ¥ボタンで3Dラベルを参考価格に差し替え、合計と注記（年・出典の但し書き）を必ず出す。
- 排他の追加: `setUse(id)` は id 指定時に重さモードを解除。`setTab` は use 以外へ移ると解除。

## B8 生きている機体と、みんなの土台（パッケージ⑧ / 2026-09-12実装）
- `S.alive`（設定「浮かせておく」・永続）。みるタブで何も選んでいない・分解0・通常モード・質問/シアター/もしも/授業/重さ/用途でないとき、0.8秒後にホバー（`alive.on`）。条件が外れると即着陸。とばすタブへ移ったときは飛行を引き継ぐ（着陸させない）。
- 生きている間もラベルを出し（`updateLabels` の live 判定）、%バッジと推力矢印は出さない（はじく・押すときだけ矢印）。ポインタの方へ yaw ±4° だけ向く（`body.lookYaw`、`stepFree` で目標を差し替え）。10秒放置で自動回転。軽量画質(0〜1)では強制オフ＋注記。
- 生きている機体を軽くタップ（8px未満・350ms未満）すると選択になる（フリックは従来どおり）。
- 大きく読む: `#bigBtn`（視点列）と設定トグル。文字1.18倍・3Dラベルを消し・`#bigBand` に選択中/ホバー中の部品名を1つだけ（28px、スマホ22px）。
  - 1.18倍が効くのは **`font-size: calc(Npx * var(--fs, 1))` と書いた規則だけ**。読む文字（`#detail` 一式・`#noteBody`・`.analogy`/`.tipbox`/`.spec`/`.trivia`/`.two-col`、授業の `.step .say`、3Dラベル `.lbl`、`#askList`、`#coach`）はすべて `--fs` を掛ける。**ドック・タブ・視点列・設定ポップの操作系は掛けない**（横一列が崩れる）。2026-09-12までこの掛け忘れで解説文がまったく大きくならなかった。
  - スマホ(≤1100px)では `#bigBand` を **シートの上**に出す（`bottom: calc(var(--sheet-h, var(--dock-h)) + 8px)` / `z-index: 15`）。`--sheet-h` は ui.js の `fold()` が開いているシートの `offsetHeight` から入れる。横向き（≤520px高）はシートが画面いっぱいなので `body.sheet-open #bigBand { display: none }`、かつ `bottomCover()` は帯を数えない（数えると機体が極端に小さくなる）。
- 言語: `S.lang ∈ ja/easy/en`（設定の先頭）。段階1 = `[data-i18n]` のUI文字・8部品の名前/役割/たとえ・12質問。40部品の解説は日本語のまま「— Japanese only —」を付ける。`partName()/partRole()/qText()/t()` を経由する。
- 読み上げ: `speak()`（Web Speech）。解説見出し・大きく帯・質問カードの🔊、設定「選ぶと自動で読む」。iOS のためクリックハンドラ内で直接呼ぶ。

## スマホ・横向きの決まりごと（2026-09-12 総点検）
- 画面の分岐は3つ: `@media (max-width: 1100px)`（右パネルをボトムシートに）/ `@media (max-width: 760px), (max-height: 520px)`（ドック・視点列の詰め）/ `@media (pointer: coarse)`（44pt・入力欄16px下限）。**coarse ブロックは CSS の末尾**に置く（前に置くと後続の宣言に負ける）。
- 視点列 `#viewCol` は**1段に収める**（`flex: 1 1 0` で幅を分け合い、全画面ボタン `#fsBtn` は消す）。折り返すと空の段が3Dを隠す（2026-09-12 の録画で発覚）。`#viewCol #fsBtn` と詳細度を上げないと `#viewCol button { display: grid }` に負ける。
- シートは `#inspector` / `#lesson` / `#expert` が同じ挙動（`bindSheet()` 1本、ui.js）。**3段デテント**: `.peek`（`max(150px, 21vh)`・つまみ＋見出しだけ。機体を眺めながら部品を突つく段）/ open（部品 56vh・専門 46vh）/ `.tall`（80vh）。つまみを上下にはじくと1段ずつ、peek からさらに下げると閉じる、つまみのタップで peek ⇄ open。**高さ ≤520px（横向き）ではすべて `height: calc(100% - 12px)`**。`✕` は 1100px 以下でだけ出す。
- シートが open/tall のときは `body.sheet-open` で視点列を畳み、tall では `body.sheet-tall` でタイトルバーも畳む（MutationObserver が class を見て付ける）。peek では戻す。
- **「帯が画面」の約束**（engine.js `applyBand` / `topCover` / `bottomCover`）: 上のバーと下のシートに挟まれた帯の中心へ `setViewOffset` で画をずらし、帯が狭まった比率ぶんカメラを引く（広がれば寄る）。`focusOn` は帯の高さで縦の必要距離を決め、`camMax()` にも `bandK()` を掛ける（掛けないと `stepCamera` の上限戻しに押し込まれる）。台本（劇場・もしも）の間は触らない。`topCover` は transition を待たず body の class で畳んだ後の形を測る。
- `env(safe-area-inset-*)` を `--sal/--sar/--sab/--sat` に持ち、`#topbar` `#dock` `#viewCol` `.popover` `#noteCard` `#massBar` の位置に足す。
- 入力欄は `font-size: max(16px, …)`（iOS のフォーカス拡大を防ぐ）。`button` 等に `touch-action: manipulation` と `-webkit-user-select: none`、`.grabber` に `touch-action: none`。
- カメラ: 引ける上限は `camMax() = 3.2 × viewScale()`。台本の引き（`flyTo`）はその場で上限を広げ、場面を抜けるときは `camHome()` で機体の枠に戻す。**固定値で clamp しない**（縦画面で場面が枠に入らなくなる）。

## B15 共有リンクと部品検索（2026-09-12実装）

## B16 飛行前の点検・確認シート / 教則の逆引き / もしも4場面（2026-09-12実装）

### 飛行前の点検・確認シート（`src/preflight.js` / `data.js` の `PREFLIGHT`）
