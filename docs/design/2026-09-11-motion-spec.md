# 動きの手触りメモ（2026-09-11 モーション設計エージェントの助言）
座標: 前=−z 右=+x 上=+y。rotation.set(rx,yaw,rz,'YXZ')。rx<0 機首下げ、rz<0 右下がり。傾き角θと低くなる側L(xz)で rz=−θ·L.x, rx=θ·L.z、加速度 a=g·tanθ·L。

## 1 フリック/スティック（free モード）
- 押下中: 指移動に1:1で傾き 0.06°/px 上限18°、沈んだ側+25%/反対−25%、全体+5%、py −10mm。
- 離す: v0 = clamp(0.45·v_finger_world, 0.15, 1.0) m/s。
- 位置ループ: Kx=34°/m Kv=12.7°/(m/s)、θ_cmd上限10°、空気抵抗c=0.8/s。(ω_pos 2.4, ζ .62 → 戻り≈2.7s、7%オーバーシュート)
- 姿勢ループ: 2次系 ω_att=14 ζ=0.70。セミインプリシット・オイラー、dt≤0.05。
- 高度: py_cmd=−0.2(1−cos|θ|)、ω=6 ζ=.8。
- 配分: collective=1/cos|θ|−1、Δ_i=κ(α_z·u.x − α_x·u.z) κ=0.0057、mult clamp .55〜1.35。
- rpm平滑: freeでは14/s。%表示はピークホールド(リリースτ.5s)、更新0.08s。
- スティック: 円形クランプ、デッドゾーン6%、エキスポ.3、θ=22°·(…)、一次遅れτ.12。速度指令モード vel_cmd=0.6·s、θ=clamp(25·(vel_cmd−vel),22°)、c=2.5。離すとフレアしてその場がホーム。ソフト境界0.22〜0.32m。
- 傾け: One Euro(minCutoff1.5, β.02) or EMA τ.08+スルー120°/s。デッドゾーン±3°、±25°でフル。ダブルタップで再センタ。
- 入力: pointerdownをcaptureで受け、pickAtヒットならstopImmediatePropagationでOrbitControlsに渡さない。指速度は機体高さの水平面との交点で。
- 上限: θ≤22°。reduced-motion: ζ_pos=1、微揺れ0。

## 2 スロー
- logTs += (log(target)−logTs)(1−exp(−dt/τ)) τ=.40減速/.30加速。プリセット 1, 1/4, 1/12, 1/50。dtSim=dt·ts(プロペラ・シム・シアター)、dtReal(浮遊・カメラ・UI)。
- クロスフェード: rpm_disp=rpm·ts。円盤 smoothstep(240,720)·.85、羽根 1−smoothstep(300,900)·.85。200〜900帯はゴースト羽根2枚(±ω·dt/3, 30%)。
- 印: 片翼の先端30%に幅6mmのつや消し白帯(uv tau>.7)。円盤に印半径で40°の尾の弧。
- 浮遊層(実時間): py 2mm@.35Hz + .7mm@1.7Hz、傾き .25°rms(.9/1.3/2.1Hz)、yaw .3°@.2Hz。スロー中×.6。

## 3 気流
- 発生: 円盤10mm下、r∈[.35R,.95R]。rate=340/s/基·(rpm/HOVER)·smoothstep(600,1500)·(1−smoothstep(.02,.2,explodeT))。プール4×250。
- v0=0.9·(rpm/HOVER)。v=−n̂v0 −.15v0 r̂ +.25v0·dir φ̂ + jitter±.06。鉛直はv0(1+.6·min(1,age/.25))へ補間。床(y<ground+.01)で v_y=0, v_r+=.6|v_y|, τ.25減衰, 寿命+.4。最長.55s。
- 粒子はラグランジュ(古い粒子は古い向き)、機体速度は継承しない。停止時は率が0へ、出た分は消える。
- 見た目: サイズ.004、フェードイン.05s、アウト.12s。light #3b7df7 α.28 Normal / dark #8fc9ff α.40 Additive。α に rpm/HOVER を焼込。
- 実装: Points1個、position/aAlpha/aSize毎フレーム更新、ShaderMaterialソフト円、depthWrite false、renderOrder 4、noPick。品質0で半分。X線/線画でも表示。
- 境界: 150粒/α.45超で煙。渦≤.25。
