# Wingtra WingtraRAY 外形の仕様書（3D手続き生成用）

作成 2026-10-30。公式の製品画像（wingtra.com・技術仕様書 v2.7・Knowledge Base の Getting started／QSG の図）、販売店（Advexure・KOREC 等）の白背景レンダー、DroneXL・YouTube の飛行写真を実際に目で見て読んだ値。
ここは「形」だけを扱う。性能などの事実は技術仕様書（`…/scratchpad/wingtra/ray-spec.txt`）を参照。

凡例：
- **［公式］**＝公式の数値・文言
- **［確認］**＝画像や図で直接確かめたこと
- **［計測］**＝写真・レンダーの画素から縮尺を出して読んだ値（根拠つき）
- **［推定］**＝根拠はあるが直接は見えていない値、または食い違う資料から折り合いをつけた値

> いちばん大事な注意（3つ）
> 1. **平面形（真上から見た形）は良い資料がある**：Knowledge Base の同梱物写真 `gs_05`（ケースと並べた真上の CG、ほぼ正射影）。翼幅1250mmを物差しにして ±1〜2% で読める。
> 2. **高さ方向（厚み・ウイングレットの垂れ下がり・フィンの高さ・モーター軸の高さ）は真横の図が見つからず、斜めのレンダー2枚（前上・前下）から逆算した［推定］**。±15〜25mm の誤差を含む。
> 3. **公式の機体寸法「125×68×12 cm」は WingtraOne GEN II の公表値と完全に同じ**（GEN II の仕様書も「125×68×12 cm（middle stand なし）」）。RAY の画像から測ると**全長は約700mm（尾部バンパー込み）**で、68cm より約2〜3cm長い。3Dは計測値（700mm）で作るのを推奨（下の「0.3」）。

## 0. 座標系と物差し

### 0.1 座標系
- 巡航姿勢で **機首＝−Z、右翼＝+X、上（背中）＝+Y**、単位 mm。
- **原点**：
  - X＝左右中心。
  - Z＝**機首先端から 280mm 後ろ**。主翼＋中央胴を一枚の翼として計算した平均空力翼弦（MAC 476mm）の 25% 点（空力中心）が機首から 279mm（下の「3.4」）なので、丸めて 280mm とした。以下、機首からの距離を `zn` と書くと **Z ＝ zn − 280**。
  - Y＝**主翼の付け根の翼弦面**（上反角はほぼ0なので翼全体の翼弦面とほぼ同じ）。胴の上下の中点はこれより約10mm上（+10）で、「胴の中心」とほぼ一致する（±10mm は推定誤差の範囲）。
- 主な位置：機首先端 Z=−280、尾部バンパー後端 Z=+422、翼端（ウイングレット外面）X=±625、背中の最高点 Y≈+70、腹 Y≈−50、ウイングレット下端 Y≈−140、フィン先端 Y≈+370。

### 0.3 寸法を読んだ方法（根拠）
1. **真上（主資料）＝ `img/kb/gs_05.jpeg`**（KB「Laid-out-Bundle-Components_2」、2000×1280、白背景、機首が左、フィン・ノーズ付き、フィンは外して横に置いてある）。
   - 機体を橙色（R−B>60）と濃灰（輝度合計<400）で切り出し、行ごとに前縁・後縁を検出（`tools/plan2.py`）。左右翼の値は **1〜3mm 以内で一致**（左右対称で、強い遠近は無い）。
   - 翼端〜翼端（橙色の外端 y=211〜1142）＝ **931px ＝ 1250mm → 1.3426 mm/px**。中心線 y=676.5（背中の黒い中心線 y≈673、バンパー中心 y≈672.5 とも一致）。機首先端 x=1284。
   - 検算①：機首〜バンパー後端 523px＝**702mm**。販売店の真上レンダー（`WintraRAY-Top-View.jpg`、遠近あり）でも翼幅基準で **710mm**。公式の 68cm より長い（上の注意3）。バンパーを除いた胴の後端（x≈1790）までだと 680mm になり、公式値はバンパー抜きの可能性もある。
   - 検算②：モーター中心の左右間隔 474px＝**636mm（X=±318）**。前上レンダーでも ±332（近いものほど大きく写る遠近込み）。
   - 検算③：KB のハードケース配置図（`gs_06.png`、ケース外形 1300mm＝1210px として 1.075mm/px）で、**電池ポケット 75×61mm（電池 69×55 に余裕）**＝縮尺が正しい。この図から **駆動系（モーター＋プロペラ）の溝の長さ 357mm**、**フィンの溝 約330〜355mm**、**ノーズコーン 幅226mm**、**ペイロード 175×190mm** を読んだ。
2. **高さ（推定）＝ 前上・前下の2枚の白背景レンダーから逆算**。
   - 前上 `WintraRAY-Front-View.jpg`：上面のエレボンのヒンジ線（zn=458）と後縁の、画像上の縦の間隔を平面図の前後差で割ると **見下ろし角 e≈19°**（sin e＝0.33、4か所で 0.31〜0.33）。これを使い「前後のずれ×sin e」を差し引いて残りを高さ（÷cos e）に換算。
   - 前下 `WingtraRAY-Bottom-View.jpg`：同じ方法で **見上げ角 ≈45°**（sin＝0.69〜0.72）。
   - 2枚とも遠近がある（近いものが大きく写る）ので、**高さ方向は ±15〜25mm の誤差**。両方で傾向が一致したものだけ採用した。
3. 斜めの写真（飛行中・立てた状態）は **形・向き・並び・色の確認だけ**に使い、寸法は読んでいない（フィンの高さの検算だけ例外、下の「7」）。

### 0.4 3Dモデル（STEP 等）
- 公式の 3D データ・外形寸法図は**見つからず**。Sketchfab API で "wingtra"/"wingtraray"/"wingtra ray" を検索 → RAY の機体モデルは 0 件（"wingtra" で出る 22 件はほぼ全部が Wingtra で撮った地形の写真測量モデル。名前だけの "Wingtra-1309"（kojirou.circle、52万面、説明なし）は中身未確認）。GrabCAD は 403 で検索不可、MakerWorld はボット確認で不可。
- AirShaper（空力解析会社）が設計の動画を公開（https://www.youtube.com/watch?v=TTX6gkR_CdM 、DroneXL 2026-10-10 記事「180 simulations」）。形状データの配布は無い。

## 2. 全体の構成［確認］
- **ブレンデッドの全翼機（ほぼ尾翼なし）＋背中に縦1枚のフィン**。胴（中央胴）は翼と滑らかにつながり、境目の線は無い（背中に浅い盛り上がり、腹は平らぎみ）。
- **テールシッター**：離着陸は機首を真上に向け、尾（後縁側）を下にして立つ。脚は **左右の翼端から下へ曲がるウイングレットの先の黒いロッド2本**＋**背中のフィン**＋**尾部バンパー**。
- **プロペラは2基、牽引式（前向き）**。主翼の前縁から突き出たゴンドラ（ナセル）の先にモーター。ホバリングもこの2基＋エレボンで行う。
- **エレボン（KB の名称は Flaps）は左右に1枚ずつ**、翼の後ろ約40%。
- **ノーズコーン（濃灰のドーム）は磁石で付く着脱部品**。外すと電池室（電池2本を前から差す）。
- 色：**全体が鮮やかな橙、機首・腹・前縁下面・エレボン後部・フィンが濃いアンスラサイト灰**。

### 3.2 上反角・ねじり［推定］
- **上反角は約0°（平ら）**：前上レンダーで上面のヒンジ線（直線・後退なし）が翼幅方向に画像上ほぼ水平（y=1219〜1225px、変化 6px 以内 ＝ 上反角 0±0.5°）。
- ねじり（ウォッシュアウト）は不明。モデルでは 0° でよい。

## 13. 「写真で確かめたこと」と「推定」の区別（まとめ）

### 写真・図で確かめたこと
- 全翼機＋背中のフィン1枚、下へ曲がるウイングレット＋後ろ向きの黒ロッド、2基の牽引式プロペラ（前縁のゴンドラ）、左右1枚ずつのエレボン、着脱ノーズ（磁石）と前から差す電池2本、腹のペイロード板（ツイストロック・カメラ窓）、腹の尾寄りのパラシュートカバー、尾部バンパー。
- 色の塗り分け（橙／濃灰／黒）、「RAY´」と「wingtra」の位置、モーターの赤（左）/緑（右）。
- ピトー管が外に無いこと、レーダー窓が見えないこと。

### 計測（画素から、縮尺の根拠つき）
- 平面形のすべて（前縁・後縁・翼弦・胴の輪郭・エレボンの範囲とヒンジ・モーターの X とプロペラ面・ロッドの位置と長さ・フィンのレール・背中の円盤と小円・文字）。
- プロペラ直径、ペイロード・パラシュートカバー・ハッチの前後位置と大きさ、電池・ノーズのケース図での大きさ。

### 推定
- 高さ方向のすべて（胴の上下面、翼の厚み、ウイングレット下端 Y≈−140、フィン高さ 330、モーター軸 Y≈−25）、上反角0°、フィンの向き（まっすぐな縁＝後縁）、回転方向、重心、立った時の3点接地のそろえ方、GNSS・レーダーの位置、電池の向き（69mm 側が左右）。
