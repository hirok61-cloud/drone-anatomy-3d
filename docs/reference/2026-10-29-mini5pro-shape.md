# DJI Mini 5 Pro 外形の仕様書（3D手続き生成用）

作成 2026-10-29（調査 10/29〜10/30）。公式の製品写真・公式取扱説明書の図・第三者（Tom's Guide）の実機写真を実際に目で見て読んだ値。
仕様（重量・性能など）の事実は同日の `2026-10-29-mini5pro-facts.md` を参照。ここは「形」だけを扱う。

凡例：
- **［確認］**＝画像や図で直接確かめたこと
- **［計測］**＝写真の画素から縮尺を出して読んだ値（根拠つき）
- **［推定］**＝根拠はあるが直接は見えていない値、または食い違う資料から折り合いをつけた値

> いちばん大事な注意：**DJI が出している真上・正面の白背景写真は、どれも遠近のかかった CG 描画**（正射影ではない）。真上写真の平面配置は ±3% 程度、高さ方向は **±5mm 程度の誤差を含む推定**。STEP 等の 3D データや外形寸法図は公開されていない（下の「0.4」）。

## 0. 座標系と物差し

### 0.1 座標系
- 機首＝**−Z**、右＝**+X**、上＝**+Y**、単位 mm。
- **原点**：X は左右中心。Z は胴の殻（シェル）の前端 z=−75 と後端 z=+75 の中間（＝ジンバルの前面より 7mm 後ろ、胴の真ん中）。Y は胴の上面（前の肩、y=+28）と胴の底面（電池の底、y=−29）のほぼ中間。
- **接地**：前脚2本の先端（y=**−63**、z=−60）と電池の底の後端（y=−29、z≈+70）の **4点（脚2＋電池底の後ろ角2）で接地**し、**機首上げ約15°で座る**［推定］（下の「6」）。水平姿勢で作る場合の「脚の先」は **y=−63**。

### 0.3 寸法を読んだ方法（根拠）
1. **真上**＝DJIストアのカルーセル画像 `car_da6c6db…jpg`（2560×2560、白背景・機首が上・展開・プロペラ付き）。
   - 縮尺：折りたたみ真上写真 `box_9cb3ee…png`（2560×2560）で、機体の全長（カメラ前端 y=260 〜 後端 y=2300 の 2040px）＝仕様の折りたたみ長さ157mm → **0.077 mm/px**。このとき、いちばん広い所（後ろの角、プロペラ以外）1235px×0.077＝**95mm＝仕様の折りたたみ幅に一致**。この縮尺で胴の前部の幅（991px）＝**76mm**。
   - 展開の真上写真で胴の前部の幅は 430px → **0.177 mm/px**（以下この値で換算。x＝(px−1280)×0.177、z＝(py−1185)×0.177）。
   - 検算①：前モーターの左右間隔 1310px＝232mm。232＋152.4（プロペラ直径）＝**384mm ≒ 仕様の展開幅380mm**（DJI は羽根を横一直線に開いた最大幅で書くとみなす）。
   - 検算②：前後モーターの間隔 847px＝150mm。150＋152.4＝**302mm ≒ 仕様の展開長さ304mm**。
   - 検算③：前ポッドの外どうし 約1420px＝**251〜256mm ≒「プロペラなし 255」**。カメラ前端〜後ポッド後端 ≒ 182mm ≒ **「181」**。→ 日本語版の「255×181×91（長さ×幅×高さ）」は **幅と長さが逆に書かれている**と判断（［推定］だが3つの検算が合う）。
   - 検算④：プロペラの羽根先〜羽根先 833px×0.177＝147mm（6.0インチ＝152mm と3%差）。
2. **正面**＝ストアの `car_27efe5…jpg`（正面やや上、約20°見下ろし）。胴の前面の幅 465px＝76mm として **0.163 mm/px**（前面の面内だけに使用）。左右の部品の位置は左右平均（写真がわずかにヨーしていて片側に約3mmずれる）。
3. **高さ**＝第三者写真2枚（どちらも机と同じ高さから撮った近距離写真で、遠近が強い）。
   - Tom's Guide `epYiNp…jpg`（**折りたたみ状態の左横**）：机〜胴の最上部（前の肩）500px＝仕様の折りたたみ高さ68mm → 0.136 mm/px（機首の面内）。
   - Tom's Guide `nYH7Vc…jpg`（展開状態の正面左、机の高さ）：同じ「前面の下ヒレの先〜胴の最上部」558px＝68mm → 0.122 mm/px。
   - 前脚の長さは、展開高さ91mm（胴の上〜脚の先）−折りたたみ高さ68mm（胴の上〜下ヒレの先）＝**脚の先は下ヒレの先より23mm下**とした（写真の目測とも、遠近を補正すれば矛盾しない）。
4. 斜めの写真（`car_e7e385`・公式ページの接写・Tom's Guide の大半）は**形・向き・並び・色の確認だけ**に使い、寸法は読んでいない。
