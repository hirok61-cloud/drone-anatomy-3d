Verge/UVify/Firefly などの欧米機はガードなし。「ショー機には必ずガードがある」とは言えない。

## 3. 共通して言えること（造形の根拠）

- **カメラもジンバルも積まない**。積むのは LED と電池だけ
- **脚がない、または非常に短い**。箱から離陸して箱に戻る運用なので、脚をつける理由がない。
  かご型は輪の下縁が着地面
- **電池は内蔵か天面の差し込み**。主役機のような外付けLiPo＋ストラップ＋XT60はない
- **灯りは胴の下に1つの大きな拡散カバー**が主流（Verge X7・EHang GD4.0・AllXF・EFY Ⅱ型）。
  上下2組で360°にする機種もある（上海雏鸟 CN-V3・レッドクリフ EMO MINI-JP）
- **RTK 測位が前提**。cm級（Verge 10cm・UVify ±0.1m・DAMODA 8mm/15mm）
- **落下傘は例外**（DAMODA V4・EFY 敏捷蜂Ⅳ型のみ）。多くは低い質量＋ジオフェンス＋自動着陸で守る

## 4. 制度との関係（一次資料で確認したもの）

- **100g未満のショー機は見つからなかった**。最軽量の EMO MINI-JP でも 249 g。
  したがって屋外のショー機はすべて無人航空機で、機体登録と登録記号の表示が台数分必要
  （航空法第2条第22項・施行規則第5条の2・解釈通達1.(2)「重量＝本体＋バッテリー」）
- **リモートIDは「特定区域の届出」で免除できる**が、**機体登録は免除されない**
  （施行規則第236条の6第2項第1号／リモートID特定区域の届出要領 国官参次第118号）。
  届出書には全機の登録記号を列挙する
- **ドローンショーは教則が「多数の者の集合する催し」の該当例そのものに挙げている**
  （教則第5版 3.1.2／解釈通達 3.(8)。「自社敷地内、無人の競技場内等、第三者の立入管理措置が
  行われていることが明白である場所での事前練習や企業向けの配信用撮影等を除く」の括弧書き付き）
- **催し場所上空には「危害を軽減する構造」が必要**とされ、審査要領はプロペラガードを例に挙げている
  （審査要領 5-5・5-6）。この教材のショー機に輪を付けているのはこの点を見せるため
- **風速5m/s以上は飛行しない**（審査要領 5-6(1)c)オ）。飛行速度と風速の和が7m/s以上も同じ）
- **型式認証を取得しているショー機はない**（型式認証一覧 令和8年6月19日現在に該当なし）。
  個別の機体認証の取得状況は公表されておらず**確認できず**
- **「1人1台」に相当する明文規定は、航空法・施行規則・審査要領・標準マニュアルのいずれにも無い**。
  多数機同時運航ガイドライン（令和8年6月・第二版）は「レベル1または2飛行に該当する
  ユースケース（例：ドローンショー）における多数機同時運航については、本ガイドラインの対象外とする」

## 5. この教材の機体に採った寸法

外形 310 mm（＝DSJ MODEL-X）／全高 113 mm（同）／モーター間 232 mm（＝EMO-JP）／
プロペラ 5インチ127 mm／質量表示 約530 g（＝EMO-JP・DAMODA V3）。
