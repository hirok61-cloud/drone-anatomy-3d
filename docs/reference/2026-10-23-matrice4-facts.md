## 1. シリーズの構成（4T と 4E の違い）

### 1.1 2機種の位置づけ
- シリーズは **Matrice 4T** と **Matrice 4E** の2機種。[S5「機体」FAQ、S1]
- 用途（原文）：「Matrice 4Tは、電力、救命救助、公共安全、森林保全など、幅広い業界に適しています。Matrice 4Eは、測量、マッピング、土木建設、採掘などの空間計測用途向けに設計されています。」[S1、S3冒頭説明]
- カメラ構成（FAQ原文の要約）[S5]
  - **4T**：1/1.3インチCMOS 48MP 広角、1/1.3インチCMOS 48MP 中望遠、1/1.5インチCMOS 48MP 望遠、**サーマル画像カメラ**、**NIR補助ライト**、レーザー距離計モジュール
  - **4E**：**4/3インチCMOS 20MP 広角**、1/1.3インチCMOS 48MP 中望遠、1/1.5インチCMOS 48MP 望遠、レーザー距離計モジュール（サーマルとNIR補助ライトは無い）
- 4Tのみ：IRカットフィルター（「Matrice 4TにはIRカットフィルターが装備されており、24時間365日の運用が可能です」）[S1]、NIR補助ライト（脚注3「Matrice 4Tでのみ利用可能です」）[S1]
- 4Eのみ：広角のメカニカルシャッター [S3]、3方向オルソキャプチャー、スマート3Dキャプチャー（脚注22「現時点ではMatrice 4Eでのみ利用可能」）、Manifold 3 と組み合わせたスマート3Dエクスプローラー [S1]、購入時 DJI Terra ライセンス1年 [S2]

### 1.2 外観の違い（言えることだけ）
- **重さ・寸法**：仕様は4T／4Eを分けずに1つの値（1219 g など）を載せている。**機種別の重量差は公式仕様では示されていない**。[S3]
- **ジンバルの頭（カメラ前面）**：マニュアルの図で前面のレンズ配置が違う。[S7 p.27]
  - 4T（図からの読み取り、正面から見た位置）：左上=5 赤外線サーマルカメラ（丸窓）、右上=2 中望遠（四角窓）、左中段=1 望遠（四角窓）、中央=3 広角（丸レンズ）、右下=6 NIR補助ライト（小さい丸）、最下段=4 レーザー距離計（横長の窓）。計6要素。
  - 4E（図からの読み取り）：左=1 望遠（大きい丸窓）、右上=2 中望遠（四角窓）、右下=3 広角（大きい四角窓）、左下=4 レーザー距離計（縦長の窓）。計4要素。
  - ジンバル本体の外形（左右側面に円筒形の部分がある箱形）は、図では両機でよく似ている（図からの読み取り）。
- **ジンバルの機械的可動範囲**も違う（チルト上限：4T 113°、4E 50°）。→ 5章
- 機体本体（胴体・アーム）の形の違いについて公式の記述は**確認できず**。マニュアルの各部名称図は4Tの全体図＋4Eのジンバル部分だけの差し込み図という構成で、本体は共通の図になっている。[S7 p.8]

### 1.3 機体の型番（法令表示用）
- 安全ガイドラインの日本語仕様欄：「機体（モデル：M4T/M4E/M4T-GA/M4T-BD/M4E-BD/JV31/JV32）」、送信機「モデル：TKPL2」。[S9 p.3〜4]
- 各型番が何を指すか（GA、BD、JV31/32）の説明は**確認できず**。

## 4. モーター配置と回転方向
- 4本アームの先端にモーター各1基（計4基、X型配置）。[S7 p.8、p.19 図]
- **各モーターの回転方向（時計回り／反時計回り）は、マニュアル・クイックスタートガイド・メンテナンスマニュアルのいずれにも記載がなく確認できず**。A／Bの区別と取り付け位置（3章）だけが示されている。
- 前アームは胴体の上寄りに、後アームは胴体の下寄りに付いているように描かれている（図からの読み取り）。[S7 p.8、p.24、p.41]

## 12. 展開・折りたたみ、電源

### 12.1 機体の準備（原文の手順）[S7 p.19、S8 p.2]
1. カメラからジンバルプロテクターを取り外す。
2. フロントアームを展開する。
3. リアアームを展開する。
4. インテリジェント フライトバッテリーの取り付け。
5. プロペラの取り付け位置をモーターに合わせる。カチッという音がして固定されるまで、プロペラを押し下げて回転させる。

### 12.2 アームの動き（図からの読み取り）
- **畳んだ状態**（S8 p.2「Charging」の1枚目、S7 p.19の1枚目）
  - 前アームは胴体上部の側面に沿って**後ろ向き**に畳まれ、前アームのモーターは機体後端付近の上側にある。
  - 後アームは胴体下部の側面に沿って**前向き**に畳まれ、後アームのモーターはジンバル横の低い位置にある。このとき**後アームのモーターは上下逆さ**（モーター軸＝プロペラ取付面が下向き、脚が上向き）に描かれている。
- **前アームの展開**（S7 p.19の2枚目、上面図・機首が上）：胴体の横で後ろ向きに畳まれたアームを、**水平面内で外側・前方へ振り出す**矢印。
- **後アームの展開**（S7 p.19の3枚目、側面図・機首が左＝機体の左側面を見ている）：胴体の下で前向きに畳まれたアームを、**下方向へ振り下ろして後方へ回す**矢印。図のアームは回転の途中の姿勢で描かれている。畳んだときにモーターが上下逆さであることと合わせると、後アームは左右方向に近い軸のまわりに大きく（半回転に近く）回ると読めるが、**回転軸の正確な向き・角度は2Dの図からは確定できない**。
- **折りたたみの手順・順番はマニュアルに記載がなく確認できず**（展開の逆順だという記述もない）。

### 12.3 電源
- 電源の入れ方：「電源ボタンを 1 回押し、次に長押しして機器の電源を入れます。」（アクティベーションの節。機体・送信機とも同じ操作）[S7 p.19]。電源ボタンを1回押すとバッテリー残量表示。[S7 p.30]
- **アームを開くと電源が入る、といった機能の記述は確認できず**。逆に次の注意がある：
  - 「機体を展開しないまま電源をオンにすると、ジンバルがセルフチェックを完了できません。」→「セルフチェック中にジンバルとアームが衝突しないよう、アームを展開した後で機体の電源を入れることをお勧めします。」[S5]
  - 「アームを展開する前にモーターを始動しないでください。」[S9 p.3]
  - 「機体の電源が入っているときは、バッテリーを挿入したり取り外したりしないでください。」[S7 p.30]
- 置き方：「機体の後方が操縦者のほうに向くように置いてください。」「機体が操縦者から 5 m 離れていることを確認」[S7 p.20]
- 着陸後は先に機体、次に送信機の電源を切る。[S7 p.11]

## 13. フロントLED・機体ステータスインジケーター [S7 p.24〜25]

- フロントLED：「機体の電源は入っているがモーターが作動していない場合、フロント LED が赤色に点灯し、機体の向きを表示します。」
- 「モーターが始動すると、フロント LED が赤色と緑色に交互に点滅し、機体ステータスインジケーターが緑色に点滅します。」
- DJI Pilot 2でフロントLEDが自動のとき、写真・動画撮影時に自動で消灯。

| 区分 | 表示 | 意味 |
|---|---|---|
| 正常 | 赤色と黄色と緑色が交互に点滅 | 電源がオンになり、自己診断テストを実行 |
| 正常 | 黄色に 4 回点滅 | ウォームアップ中 |
| 正常 | 緑色にゆっくり点滅 | GNSS が有効 |
| 正常 | 緑色に 2 回点滅を繰り返す | ビジョンシステムが有効 |
| 正常 | 黄色にゆっくり点滅 | GNSS およびビジョンシステムが無効（ATTI モードが有効） |
| 警告 | 黄色にすばやく点滅 | 送信機信号消失 |
| 警告 | 赤色にゆっくり点滅 | 離陸不可（例：ローバッテリーなど） |
| 警告 | 赤色にすばやく点滅 | 重度のローバッテリー |
| 警告 | 赤色点灯 | 重大なエラー |
| 警告 | 赤色と黄色に交互に点滅 | コンパス キャリブレーションが必要 |

- ビーコン：機体に内蔵、夜間の位置把握用、DJI Pilot 2で手動オン／オフ。[S7 p.25]。夜間飛行では「ビーコンと底部補助ライトが有効になっていることを確認」。[S7 p.17]
- フロントLEDと機体ステータスインジケーターが左右両側のアームにあるか（片側だけか）は、図の指示線が片側だけのため**確認できず**。メンテナンスマニュアルには点検項目「Frame Arm LEDs」がある。[S10 p.10]
