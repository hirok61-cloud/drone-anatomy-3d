## 0. 座標系と物差し

- 機首＝−Z、右＝+X、上＝+Y、単位 mm。
- **原点**：Z は胴（上ぶた）の前端 z=−111.4 と後端 z=+111.4 の中間。Y は胴の上面（上ぶたの天面、接地面から約126mm）と下面（底板、接地面から約38mm）の中間＝**接地面から82mm**。よって**脚の先（接地面）は y=−82**。
- 参考：4つのモーターの中心の平均（推力中心）は z≈+39（原点より39mm後ろ）。前モーターは鼻先の真横、後モーターは胴の後端より約67mm後ろにある、前寄りの胴。

### 物差しにした公式寸法（仕様ページ https://enterprise.dji.com/jp/matrice-4-series/specs）
| 項目 | 値 |
|---|---|
| 展開時（プロペラなし） | 307.0 × 387.5 × 149.5 mm（長さ×幅×高さ）「最大寸法（プロペラを除く）」 |
| 折りたたみ時 | 260.6 × 113.7 × 138.4 mm |
| 対角ホイールベース | 438.8 mm |
| プロペラ | 10.8インチ（約274mm）、型式 1157F（標準）／1154F（低騒音） |

### 寸法を読んだ方法（根拠）
1. **真上の図**＝取説 v1.2 p25「4.3 ビーコン」の線画（真上・正射影に近い）。PyMuPDF で12倍に書き出し（以下「top12」）、画素を走査。
   - モーター中心（プロペラの軸の小円）：左前(391,481)・右前(1487,476)・左後(462,1327)・右後(1417,1323) px。
   - 対角（左前↔右後）1327px／（右前↔左後）1332px、平均1329.8px＝438.8mm → **0.330 mm/px**。
   - 検算：前モーター外縁どうし（中心±40px）1176px×0.330＝**388mm**（仕様387.5mm）。一致。
   - 検算：前アームの付け根から前モーターまで約153mm → 折りたたむとモーターが胴の後端に来る → 「カメラ前面〜折りたたんだ前モーターの後縁」＝**約259mm**（仕様の折りたたみ長さ260.6mm）。一致。
   - 検算：胴の最大幅88mm＋折りたたんだ前アーム（幅約13mm）×2＝**114mm**（仕様の折りたたみ幅113.7mm）。一致。
2. **正面の図**＝AS1スピーカー／AL1スポットライト取説 v1.2 の p3（PDF 5ページ）右図（スポットライトを付けた正面図）。16倍に書き出し（以下「front16」）。前モーター中心の左右間隔1547px＝361.6mm（真上図の前トレッド） → **0.2326 mm/px**。前の魚眼2基の間隔 274px＝63.7mm、真上図・上面図（同取説の左図）とも一致。ただしこの図は弱い遠近がかかっていて（後モーターの間隔が7%小さく見える）、脚が長めに描かれている疑いがある（下の 3. で補正）。
3. **高さ**＝Heliguy の実機写真 `matrice-4-series-gallery-1.jpg`（机上・ほぼ水平の正面）。前の魚眼2基の間隔154px＝63.7mm → **0.414 mm/px**。GNSS頂部は（遠近を補正して）接地面から約146mm＝仕様の高さ149.5mmとほぼ一致したので、高さはこの写真を主、正面図を従とした。
4. 斜めの写真は寸法に使っていない（向き・形・比率の確認だけ）。

### 解けていない食い違い（重要）
- 真上図の形のままだと「カメラ前面〜後モーター後縁」は約328mmで、仕様の展開長さ307.0mmより21mm長い。対角・全幅・折りたたみ長さ・折りたたみ幅はすべて真上図と一致するので、**仕様の展開長さはカメラ（ジンバル）の張り出しを含まない値**（前モーター前縁〜後モーター後縁＝305mm）と考えるのが最も整合する。3Dは真上図の配置で作るのを推奨。
- 取説の線画のプロペラは約297mm相当に描かれていて、仕様10.8インチ（274mm）より大きい。線画のプロペラは誇張とみなし、**直径274mm**で作る。

## 2. 胴

### 2.1 全体の構成［確認］
- 胴は**「上ぶた（フード）」と「下胴」の2段**。上ぶたは平らな天面の帽子形で、前端が丸い「眉（ブロウ）」になってカメラの上にかぶさる。下胴は上ぶたの下に収まり、後ろからバッテリーが入る。
- カメラ（ジンバル）は**鼻先の下にぶら下がる**（Mavic 4 Pro のように胴の前面に半分埋まる球ではない）。下胴の前端の左右に「頬（ほお）」の柱があり、その間のくぼみにジンバルが入る（gallery_11）。
- 天面の後ろ寄りに**円筒形のGNSSアンテナ**が立つ（取説 p8 の12）。これが最も高い点で、他機種との一番の見分けどころ。

### 2.4 正面から見た断面［計測は鼻先のみ、他は推定］

- 上ぶたの断面：天面は平ら、肩は R≈10、側面はほぼ垂直。
- 下胴の断面：上ぶたより左右とも数mm内側で、下の角は R≈8。底は平らな底板。
- 前アームの付け根は上ぶたの下、胴の側面の中ほどから出る（下の 4. 参照）。

## 10. 折りたたみ

### 10.1 動き［確認：取説 p19・同梱物の線画・f384・matrice_4_series_gallery・M4T-3・5168f7］
- **前アーム**：付け根の**ほぼ垂直な軸で水平に後ろへ約113°振る**（右アームは上から見て時計回り＝+Y軸まわり −113°、左は +113°）。たたむと胴の**上側の側面**に沿って後ろ向きに寝る。**モーターは上向きのまま、脚は下向きのまま**。前モーターは胴の後端（GNSS・ビーコンの左右、z≈+111）に来る（M4T-3 の真上写真で確認）。
- **後アーム**：付け根の**傾いた軸で下へ振り下ろしながら前へ180°**回す（取説 p19 の図で途中は真下を向く）。たたむと胴の**下側の側面**に沿って前向きに寝て、**モーターは逆さ（取付座が地面側）、脚は上向き**。逆さのモーターはジンバルの斜め後ろ・左右（z≈−56）で地面に着く（f384・matrice_4_series_gallery で確認）。
- 回転軸（推定）：後アームは「展開時の向き」と「たたんだ向き」の二等分の水平軸まわりに180°（右後ろなら軸 ≈ (0.90, 0, −0.44)＝外向き・前へ約26°）。前アームの軸は、折りたたみ高さ（138.4mm）が展開高さより約11mm低いことから、**わずかに傾いていて、たたむと前脚の先が約10mm持ち上がる**と推定（たたんだ機体は、逆さの後モーターと持ち上がった前脚で接地する）。
- プロペラ：前モーターのプロペラはたたんだアームに沿って前向きに上側へ、後モーターのプロペラは胴の下側へ寝る（f384 で上にオレンジの先端、下に黒い羽根が見える）。
- ジンバルプロテクター（グレーのカバー）をたたんだ時にカメラにかぶせる（取説 p19 の1）。

## 14. 写真で確かめたこと／推定の区別

### 写真・図で確かめたこと［確認］
- 胴が上ぶた＋下胴の2段で、天面後ろに円筒のGNSS、その後ろにビーコン、左右に斜めスリットの排気口、前寄りに dji ロゴの板（セルラードングルのふた）と E-Port のゴムぶたが並ぶこと。
- 上の魚眼が四隅（前2・後2）にあること。底面に前後2基の下方カメラ・3D赤外線（2分割の横長窓）・補助ライトが一列に並び、暗い放熱板の上にあること。
- 4本の脚がすべて接地すること（4点着地）。前脚が内側へ傾くこと。
- 前アームが水平に後ろへたたまれ（モーター上向き）、後アームが下を回って前へたたまれ、モーターが逆さになること。展開は前アーム→後アームの順。
- フロントLEDが前ポッド前面に左右とも有り、写真では左が赤・右が緑。ステータスインジケーターが後ポッドの先端。
- 「Matrice 4」の文字は左前アームだけ。プロペラは黒＋オレンジ先端、A/Bの印と取り付け位置。
- 4T・4E の窓の並び（向かって左＝機体の右）、白い窓（4T のレーザー・NIR）、4T の頭の上の全幅フィン、4E の右上の丸い望遠鏡筒と左上の小フィン。
- バッテリーが後ろから入り、後端キャップに電源ボタン・LED4個・左右バックル。後面下部に六角メッシュ吸気口2つとUSB-C／microSD。
- アクセサリーは天面の E-Port に付き、スポットライトは胴の左右に大きくはみ出す。

### 図・写真の画素から計測した値［計測］
- モーター位置（±180.8, −101.0）（±157.6, +178.4）、アームの振り角 23°／39°、アーム幅、胴の幅の推移、GNSS・E-Port・排気口・ビーコンの位置（真上図、0.330mm/px）。
- 鼻先の幅80mm、魚眼の間隔63.7mm、ジンバル頭の大きさ、左右円筒、モーター直径（正面図、0.2326mm/px）。
- 高さ：魚眼 y=+27、ジンバル下端 y≈−60、前アームの下がり約5°、前後モーターの高さの差約3mm（机上写真、0.414mm/px）。
- 4T のレンズ位置（18b8、頭の幅62mm換算）、4E のレンズ位置（正面図）。

### 推定
- 横から見た上面・下面の高さの推移（真横の図・写真が無い）。胴の下面 y=−44。
- 底面の部品の z 位置（±15mm）。後ろの魚眼の高さ。バッテリーの差し込み深さ。ジンバル頭の奥行き。
- ジンバルのヨーク（腕）の構成（頭の後ろに隠れて見えない）。
- 前アームのヒンジ軸の傾き（折りたたみ高さの差からの逆算）、後アームの回転軸。
